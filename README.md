# 🌦️ Weather App (Updated Version)

A **simple, beautiful, and modern Android Weather Application** built using **Java** and **Android Studio**.

This project is an **updated version** of the original Weather App. Since the original project relied on the **OpenWeatherMap One Call API** (which is now a paid service for new users), the application has been **completely migrated to WeatherAPI.com**, allowing anyone to run the project using a **free API key**.

The goal was to keep the original UI and user experience while updating the backend API so the application works perfectly with the latest Android development environment.

---

# ✨ Features

- 📍 Detect current location using GPS

# ☁️ Weather API Setup

This project uses **WeatherAPI.com** to fetch real-time weather information.

## Step 1

Create a free account:

👉 https://www.weatherapi.com/

---

## Step 2

Generate your **free API key** from the dashboard.

---

## Step 3

Open the following file:

```java
LocationCord.java
```

Replace the API key with your own:

```java
public static final String API_KEY = "YOUR_WEATHERAPI_KEY";
```

# 🚀 How to Run

1. Clone this repository

```bash
git clone YOUR_REPOSITORY_LINK
```

2. Open the project in Android Studio.

3. Install all required SDK components.

4. Replace the WeatherAPI key inside:

```java
LocationCord.java
```

5. Sync Gradle.

6. Run the application.
